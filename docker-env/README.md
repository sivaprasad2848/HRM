# HRM Django Base Environment

Dockerized Python/Django base environment for HRM project development.

## Included
- Python 3.12
- Django
- Gunicorn
- Git
- Curl
- Nano
- Build tools

## Build Image

docker build -t hrm-django-base:v1 .

## Pull from Docker Hub

docker pull gshnupp/hrm-django-base:v1
